# Glyphbridge

**Бесплатный офлайн-переводчик с открытым исходным кодом для любой письменности — от современных языков до османского турецкого, иероглифов и клинописи.**

🌐 [English](../../README.md) · [Türkçe](README.tr.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · **Русский** · [العربية](README.ar.md) · [हिन्दी](README.hi.md) · [中文](README.zh.md) · [日本語](README.ja.md)

> ⚠️ **Статус: ранняя разработка.** Glyphbridge создаётся открыто. Функции с пометкой *запланировано* пока не существуют — будем рады вашей помощи.

## Почему Glyphbridge?

- **Бесплатно навсегда** — открытый код под лицензией Apache 2.0, без регистрации; API-ключи нужны, только если вы открываете свой сервер в сеть.
- **Приватно и офлайн** — всё работает на вашем компьютере; документы никуда не отправляются.
- **Легко** — рассчитан на обычный ПК с **8 ГБ ОЗУ**, без видеокарты.
- **Честно о качестве** — у каждого перевода есть **оценка уверенности**, а качество (COMET / chrF) публикуется для каждой языковой пары.
- **Для любой письменности** — текст, фото, документы, речь и исторические системы письма.

| Версия | Возможность | Статус |

| **Эксперимент** | **Египетские иероглифы** и **клинопись** (аккадский, шумерский) — совместно с исследователями | 🔬 Исследование |

## Используйте где угодно (запланировано)

| Интерфейс | Пример |
|---|---|
| Библиотека Python | `glyphbridge.translate("Merhaba", to="en")` |
| Командная строка | `glyphbridge translate file.pdf --to de` |
| REST API | `glyphbridge serve` → `POST /v1/translate` (необязательный API-ключ) |
| ИИ-агенты (MCP) | Используйте как инструмент в Claude и других ИИ-ассистентах |
| OpenAI-совместимый эндпоинт | Подключайте к существующим ИИ-инструментам без изменения кода |

Всё размещается у вас и бесплатно. API-ключи защищают ваш сервер, если вы открываете его в сеть.
