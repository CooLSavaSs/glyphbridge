## لماذا Glyphbridge؟

- **مجاني إلى الأبد** — مفتوح المصدر برخصة Apache 2.0، بلا تسجيل؛ مفاتيح API فقط إذا أتحت خادمك الخاص على الشبكة.
- **خاص ويعمل دون إنترنت** — كل شيء يعمل على حاسوبك، ولا تغادره مستنداتك أبدًا.
- **خفيف** — مصمم ليعمل جيدًا على حاسوب عادي بذاكرة **8 غيغابايت**، دون بطاقة رسوميات.
- **صادق بشأن الجودة** — كل ترجمة تأتي مع **درجة ثقة**، وننشر الجودة المقيسة (COMET / chrF) لكل زوج لغات.
- **لكل أنظمة الكتابة** — النصوص والصور والمستندات والكلام وأنظمة الكتابة التاريخية.

## استخدمه في أي مكان (مخطط له)

| الواجهة | مثال |
|---|---|
| مكتبة Python | `glyphbridge.translate("Merhaba", to="en")` |
| سطر الأوامر | `glyphbridge translate file.pdf --to de` |
| واجهة REST API | `glyphbridge serve` → `POST /v1/translate` (مفتاح API اختياري) |
| وكلاء الذكاء الاصطناعي (MCP) | استخدمه كأداة من Claude ومساعدي الذكاء الاصطناعي الآخرين |
| نقطة نهاية متوافقة مع OpenAI | اربطه بأدوات الذكاء الاصطناعي الحالية دون تغيير الشيفرة |

كل شيء مستضاف ذاتيًا ومجاني. تحمي مفاتيح API خادمك عند إتاحته على الشبكة.
