## Glyphbridge क्यों?

- **हमेशा मुफ़्त** — Apache 2.0 लाइसेंस के तहत ओपन सोर्स, कोई पंजीकरण नहीं; API कुंजी तभी जब आप अपना सर्वर नेटवर्क पर खोलें।
- **निजी और ऑफ़लाइन** — सब कुछ आपके अपने कंप्यूटर पर चलता है; आपके दस्तावेज़ कहीं नहीं जाते।
- **हल्का** — **8 GB RAM** वाले सामान्य कंप्यूटर पर, बिना GPU के, अच्छी तरह चलने के लिए बनाया गया।
- **गुणवत्ता के बारे में ईमानदार** — हर अनुवाद के साथ एक **विश्वास स्कोर** मिलता है, और हम हर भाषा-जोड़ी की मापी गई गुणवत्ता (COMET / chrF) प्रकाशित करते हैं।
- **हर लिपि के लिए** — पाठ, तस्वीरें, दस्तावेज़, बोली और ऐतिहासिक लेखन प्रणालियाँ।

## कहीं भी इस्तेमाल करें (योजनाबद्ध)

| इंटरफ़ेस | उदाहरण |
|---|---|
| Python लाइब्रेरी | `glyphbridge.translate("Merhaba", to="en")` |
| कमांड लाइन | `glyphbridge translate file.pdf --to de` |
| REST API | `glyphbridge serve` → `POST /v1/translate` (वैकल्पिक API कुंजी) |
| AI एजेंट (MCP) | Claude और अन्य AI सहायकों में टूल की तरह इस्तेमाल करें |
| OpenAI-संगत एंडपॉइंट | बिना कोड बदले मौजूदा AI टूल्स से जोड़ें |

सब कुछ स्वयं-होस्ट किया गया और मुफ़्त है। जब आप अपना सर्वर नेटवर्क पर खोलते हैं, तो API कुंजियाँ उसकी सुरक्षा करती हैं।
