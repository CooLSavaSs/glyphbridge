## なぜ Glyphbridge？

- **ずっと無料**——Apache 2.0 ライセンスのオープンソース。登録不要で、API キーは自分のサーバーを公開する場合にのみ使います。
- **プライベートでオフライン**——すべてあなたのパソコン上で動作し、文書が外部に送られることはありません。
- **軽量**——GPU なし、**8 GB RAM** の一般的なパソコンで快適に動くよう設計しています。
- **品質に正直**——すべての翻訳に**信頼度スコア**を付け、言語ペアごとの実測品質（COMET / chrF）を公開します。
- **あらゆる文字に対応**——テキスト、写真、文書、音声、そして歴史的な文字体系。

## 機能とロードマップ

| バージョン | 機能 | 状態 |
|---|---|---|
| **v0.1** | テキスト翻訳、最初の 10〜20 言語、コマンドライン + シンプルな UI、量子化モデル（int8） | 🚧 開発中 |
| **v0.2** | **画像**（OCR）や**文書**（PDF、DOCX）内の文字をレイアウトを保ったまま翻訳；信頼度フィルター | 📋 予定 |
| **v0.3** | **音声**翻訳：音声 → テキスト → 翻訳 → 音声 | 📋 予定 |
| **v0.4** | **オスマン・トルコ語**：活字・手書き（ルクア、ディーワーニー）の OCR、翻字、現代トルコ語 | 📋 予定 |
| **実験的** | **エジプトのヒエログリフ**と**楔形文字**（アッカド語、シュメール語）——研究者と協力 | 🔬 研究 |

## どこでも使える（予定）

| インターフェース | 例 |
|---|---|
| Python ライブラリ | `glyphbridge.translate("Merhaba", to="en")` |
| コマンドライン | `glyphbridge translate file.pdf --to de` |
| REST API | `glyphbridge serve` → `POST /v1/translate` (API キーは任意) |
| AI エージェント（MCP） | Claude などの AI アシスタントからツールとして利用 |
| OpenAI 互換エンドポイント | コードを変えずに既存の AI ツールへ接続 |

すべてセルフホストで無料です。サーバーをネットワークに公開する場合は API キーで保護します。
